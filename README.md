# Restaurant Analytics Dashboard (Power BI)

## Project Overview

This project analyzes restaurant data using Power BI to identify customer preferences, restaurant performance, pricing trends, online delivery patterns, and geographical distribution. The dashboard provides interactive visualizations that help stakeholders make data-driven business decisions.

---

## Objectives

- Analyze restaurant distribution across countries and cities
- Identify the most popular cuisines
- Study customer ratings and sentiments
- Analyze pricing categories
- Compare online delivery and table booking services
- Discover top restaurant chains
- Generate actionable business insights

---

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Business Insights

- Nearly 79% of restaurants belong to lower and medium price categories.
- India contributes the highest number of restaurants in the dataset.
- Popular restaurant chains have significantly more outlets but do not always achieve the highest ratings.
- Customer sentiment is predominantly Neutral and Positive.
- Online delivery adoption varies across countries and restaurant categories.
